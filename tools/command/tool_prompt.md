## command_runner 工具

用途: 在本地 shell 中执行命令，并返回退出码、标准输出 stdout 和标准错误 stderr。

何时使用:
- 用户要求运行一个命令并查看结果时
- 需要查看当前目录、Python 版本、环境信息时
- 需要运行简单脚本、测试命令或演示命令时
- 需要通过命令行验证文件是否创建成功时

何时不要使用:
- 只是读取文件内容 → 优先用 file_reade
- 只是写入文件内容 → 优先用 file_write
- 只是编辑文件 → 优先用 file_edit
- 只是搜索文件 → 优先用 file_glob / file_grep
- 不要执行需要交互输入的命令
- 不要执行来源不可信的命令

参数:
- command (必填): 要执行的 shell 命令。例如 `python --version`、`ls -la`、`echo hello`
- timeout (可选): 超时时间，单位秒，默认 120，最大 120

安全模型（白名单模式）:
- 只允许执行白名单中的命令和 flag
- 不在白名单的命令 → 直接拒绝
- 不在白名单的 flag → 直接拒绝
- 命令注入检测: $()、``、重定向、换行符、ANSI-C引用
- 破坏性操作（git reset --hard 等）→ 拒绝
- 管道中的命令也要在白名单中
- 写操作不能操作系统关键路径（/etc、/boot 等）

注意事项:
- 命令在本机执行，可能影响真实文件和环境
- Windows 下建议使用简单命令
- 如果命令输出很长，阅读结果时应关注退出码和关键错误信息

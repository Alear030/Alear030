## 三级体裁

`docs/` 下的文档按内容体裁分三层，新增文档时对号入座即可：

- **总览文档**（`docs/` 根）：跨模块的整体说明，面向第一次读这个项目的人
- **模块机制文档**（`docs/modules/<module>.md`）：单个模块「现在是什么样」，文件名对齐 [CLAUDE.md](../CLAUDE.md) 「稳定模块地图」里的模块名
- **设计叙事文档**（`docs/design/<topic>.md`）：单个机制「为什么长成这样」，和机制文档解耦，不强制配英文版

只有已经写出实质内容的文档才会出现在下面的列表里；尚未成文的模块不预留占位链接。

# 技能使用原则

以下内容为**技能使用注意事项**，下方会罗列当前可用的技能列表（技能名称+技能描述），使用技能前需要**严格遵循**下述原则

## 技能使用原则

**匹配描述而非字面指令，任务特征命中description即可触发，不要求用户说出技能名**

**先取内容再执行，命中技能后必须调用skill_load获取完整技能内容，不要凭description猜测技能内容就动手执行**

**命中技能但尚未调用skill_load之前，第一个动作必须是skill_load本身，不允许被其他工具调用抢先；哪怕已经想到具体的确认问题，也必须先skill_load拿到完整内容后再问，不能先凭猜测发起确认（是否同意创建、是否继续这类不依赖技能具体内容的单纯授权确认除外）**

**技能以列表为准，不要凭空使用下方列表中不存在的技能**

**技能不冲突默认可以叠加使用，多个技能同时命中且不矛盾时可以配合使用，而不是只选一个**

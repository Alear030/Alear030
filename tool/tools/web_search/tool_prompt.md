## web_search 工具说明

用途: 批量并行搜索多个关键词，每个关键词独立检索，返回相关网页的标题、链接、概述。

### 何时使用:
- 需要联网获取当前信息、事实核查、了解某个话题的最新进展时
- 有多个互相独立的关键词需要分别搜索时，一次调用即可全部并行处理，不必逐个调用
- 不确定某个术语/项目/事件的具体信息，需要先搜索定位时

### 何时不要使用:
- 已经有明确的目标 URL，只是想看页面具体内容 → 直接用 web_fetch，不必先搜索
- 问题可以直接从已有上下文或历史记忆中回答 → 优先用 memory_recall 或直接回答，不必联网

### 参数说明:
- key_words (必填): 搜索关键词列表，1 个或多个。每个元素是一次独立搜索的查询短语，多个关键词并行检索、互不阻塞。

调用示例：
{"key_words": ["Anthropic 公司 简介", "Anthropic 最新动态 2026", "Anthropic Claude 模型"]}

写法建议：
- 优先用「实体 + 限定词」的完整查询短语（如 "Anthropic 公司 简介"），带消歧上下文的查询通常比过短词更精准，实测零噪音
- 不必刻意把查询拆成单一概念再逐词搜索；查询短语整体作为单个关键词即可
- 避免仅用高歧义短词（如 "Anthropic 融资" 可能命中同名宇宙学术语"人择原理"），必要时加消歧限定（如 "Anthropic 公司 融资"）
- 不要把多个相互独立、需要分别检索的主题硬塞进同一个关键词（如 "Anthropic 融资 估值 IPO"）

### 调用后:
- 返回 JSON 数组，每个元素为 `{"key_word": 关键词, "result": 该关键词的搜索结果文本}`
- 单个关键词返回的 result 内部按 `标题：... 链接：... 描述：...` 的格式列出多条结果，用空行分隔
- 某个关键词搜索失败时，只影响它自己的 result（内容为失败说明），不影响其他关键词的正常返回

### 注意事项:
- 单次批量数量建议控制在合理范围内（如不超过 5-8 个），避免一次提交过多关键词
- 失败会自动重试，仍失败才会在对应 result 里返回失败说明，不需要自行重复调用同一关键词

## file_read 工具

用途: 读取本地文本文件的内容，并用类似 `cat -n` 的格式给每一行加上行号。

### 何时使用:
- 用户要求查看某个本地文件内容时
- 需要检查代码、配置文件、日志文件、Markdown 文档时
- 回答问题前需要先读取文件真实内容时
- 文件较长时，可以用 offset 和 limit 分段读取

### 何时不要使用:
- 目标路径是目录而不是文件时（用 command_runner 的 dir/ls 查看目录）
- 需要读取网页内容时（应使用网页抓取工具）
- 需要修改文件内容时（应使用 file_writer）
- 不确定文件路径时，先询问用户或使用其他方式确认路径

### 参数:
- file_path (必填): 文件的绝对路径。例如 D:\\project\\main.py
- offset (可选): 从第几行开始读取，默认 0。注意这是从 0 开始计数的偏移量
- limit (可选): 最多读取多少行，默认 2000，最大 2000

### 注意事项:
- 只读取 UTF-8 文本文件，非 UTF-8 文件会报错
- 返回内容会带行号，方便引用具体位置（行号从 1 开始）
- 如果文件不存在、路径是目录、文件为空，会返回对应的提示信息
- 一次最多读取 2000 行，长文件请分多次读取

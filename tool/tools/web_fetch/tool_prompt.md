## web_fetch 工具说明

用途: 批量并行抓取多个 URL 的网页内容，每个 URL 独立抓取，返回去除脚本/样式后的正文文本。

### 何时使用:
- 已经有明确的目标 URL（如 web_search 返回的链接），需要查看页面具体内容时
- 有多个互相独立的 URL 需要分别抓取时，一次调用即可全部并行处理，不必逐个调用

### 何时不要使用:
- 还不知道具体 URL，只有一个模糊的话题或关键词 → 先用 web_search 搜索定位，再用本工具抓取
- 目标是本地文件而非网页 → 用 file_read，不要传本地路径给本工具

### 参数说明:
- urls (必填): URL 列表，可以是 1 个或多个。多个 URL 会并行抓取，互不阻塞

### 调用后:
- 返回 JSON 数组，每个元素为 `{"url": URL, "content": 页面文本或失败说明, "success": 是否抓取成功}`
- `success` 为 true 时 `content` 是正文文本；为 false 时 `content` 是失败说明
- 正文文本已去除 script/style/nav/footer/header 标签，并截断到 5000 字符
- 某个 URL 抓取失败时，只影响它自己的 content（内容为失败说明），不影响其他 URL 的正常返回

### 注意事项:
- 单次批量数量建议控制在合理范围内（如不超过 5-8 个），避免一次提交过多 URL
- 单个 URL 失败会自动重试 3 次，仍失败才会在对应 content 里返回失败说明，不需要自行重复调用同一 URL
- 部分网站可能因反爬策略、需要 JS 渲染等原因抓取不到有效正文，此时应换用 web_search 获取的摘要信息，而非反复重试同一 URL

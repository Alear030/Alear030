## file_edit 工具

用途: 对本地已存在的文本文件做局部字符串替换，不需要覆盖整个文件内容。

何时使用:
- 只需要修改文件中的一小部分内容（例如改一行代码、替换一段配置）
- 文件较大，重新生成整份内容成本高或容易遗漏其他部分
- 已经用 file_read 看过文件内容，明确知道要替换的原文和目标文本

何时不要使用:
- 目标文件还不存在时（应使用 file_write 创建新文件）
- 需要重写文件的绝大部分内容时（直接用 file_write 整体覆盖更简单可靠）
- 不确定要替换的原文具体是什么时，先用 file_read 查看确认

参数:
- file_path (必填): 要编辑的文件绝对路径
- old_string (必填): 要被替换的原始文本，必须和文件中的内容逐字符一致（包括缩进、换行、空白）
- new_string (必填): 替换后的新文本
- replace_all (可选): 默认 False，只替换一次。如果 old_string 在文件中出现多次且确实都要替换，传 True

注意事项:
- old_string 必须在文件中唯一匹配，否则会报错要求提供更多上下文，或显式传 replace_all=True
- old_string 未在文件中找到时会报错，不会做任何修改
- 使用 UTF-8 编码读写，不支持非 UTF-8 文件
- 同样受路径限制，只能编辑工作空间或技能目录内的文件

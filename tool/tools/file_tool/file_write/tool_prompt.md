## file_writer 工具

用途: 创建新的本地文本文件，或覆盖已有文本文件的全部内容。

何时使用:
- 用户明确要求创建文件时
- 用户明确要求保存一段文本、代码、配置或说明文档时
- 需要把工具运行结果写入本地文件时
- 需要生成示例文件用于演示时

何时不要使用:
- 用户只是想查看文件内容时（应使用 file_reader）
- 只想追加内容但不想覆盖原文件时（本工具会覆盖整个文件）
- 文件路径不明确时，先向用户确认
- 不应写入系统关键目录或用户没有明确授权的位置

参数:
- file_path (必填): 要写入的文件绝对路径。例如 D:\\project\\notes\\demo.txt
- content (必填): 要写入文件的完整文本内容

注意事项:
- 如果父目录不存在，会自动创建父目录
- 如果文件已经存在，会直接覆盖原内容，并在结果中给出警告
- 使用 UTF-8 编码写入
- 这是教学 Demo，没有实现复杂的权限确认和版本备份"""

## file_glob 工具

用途: 按文件名模式（glob）在指定目录下查找文件，返回按修改时间从新到旧排序的文件路径列表。

何时使用:
- 需要按文件名/扩展名查找文件，但不知道文件确切在哪个子目录时
- 需要确认某个目录下有哪些符合命名规则的文件（例如所有 .md 文件）
- 想找到最近修改过的匹配文件时

何时不要使用:
- 已经知道确切文件路径时，无需再查找
- 需要按文件内容搜索时（应使用 file_grep）
- 只想查看某个目录的完整清单而非按模式过滤时（用 command 的 dir/ls）

参数:
- pattern (必填): glob 匹配模式，例如 `*.py`、`**/*.md`（`**` 表示递归任意层级子目录）
- path (可选): 搜索起始目录的绝对路径，默认为工作空间根目录

注意事项:
- 只匹配文件，不返回目录
- 结果按最后修改时间从新到旧排序
- 单次最多返回 200 条结果，超出会提示缩小 pattern 范围
- 搜索范围默认限制在工作空间内，传入工作空间外的 path 时请谨慎确认是否合理

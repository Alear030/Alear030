## file_grep 工具

用途: 在指定目录（默认工作空间）或单个文件中，按正则表达式搜索文本内容，返回匹配的文件路径、行号和行内容。

何时使用:
- 需要在多个文件里查找某个函数名、关键字、配置项时
- 不确定内容具体在哪个文件的哪一行，需要先定位再用 file_reader 精确读取时
- 需要确认某段文本是否已存在于文件中时

何时不要使用:
- 已经明确知道文件路径和大致行号时，直接用 file_reader 读取更直接
- 只是想按文件名/路径找文件，而不关心文件内容时（应使用 file_glob）
- 需要修改内容时（应使用 file_edit 或 file_write）

参数:
- pattern (必填): 要搜索的正则表达式（Python re 语法），普通文本也可直接作为 pattern 使用
- path (可选): 搜索的目录或文件绝对路径，默认为工作空间根目录
- glob (可选): 在目录搜索时，先按文件名 glob 模式过滤（如 `*.py`、`**/*.md`），不传则搜索所有文件

注意事项:
- 无法用 UTF-8 解码的文件（图片、二进制文件等）会被自动跳过，不会中断搜索
- 单次最多返回 200 行匹配结果，超出会提示用 glob 缩小范围
- 搜索范围默认限制在工作空间内，传入工作空间外的 path 时请谨慎确认是否合理

## plan_mode_on 工具

用途: 激活指定 plan 进入执行模式。用户确认计划后调用此工具，将 plan 状态从 pending 切换为 in_progress。

调用前必须做的事:
- plan 必须是通过 plan_design 创建或修改出来的，且其内容已完整展示给用户
- 必须等待用户在新一轮消息中做出明确回应（例如"可以"、"开始吧"、"没问题"）。**不能**在调用 plan_design 的同一轮对话里紧接着调用 plan_mode_on，那样等于自己代替用户确认

调用规则: 调用 plan_mode_on 后系统会强制结束本轮对话（同批次内排在其后的其他工具调用会被系统跳过，不会真正执行），无需自行留意。系统将在下一轮自动注入 plan 的下一步骤。

何时使用:
- 用户已在明确回应中确认 plan 内容符合预期、同意开始执行

何时不要使用:
- plan 尚在创建或修改阶段，未获得用户确认
- plan_design 刚生成/修改了计划，但用户还没有在新一轮回复中给出明确确认（同一轮内紧接调用视为未确认）
- plan 已经在执行中或已完成
- 用户未确认计划内容

参数:
- plan_file (必填): plan 文件名（不含路径和 .json 后缀）

调用后的行为:
- plan 状态从 pending 切换为 in_progress
- session 进入 plan 模式
- 系统自动结束本轮，同批次内此工具之后的其他工具调用会被跳过

## plan_create 工具

用途: 创建结构化的分步执行计划，将复杂任务拆解为可执行、可验证的步骤序列。调用后计划写入本地文件，系统自动进入 plan 执行模式。

何时使用:
- 用户的任务需要多个步骤才能完成，且步骤之间有明确的依赖关系
- 任务涉及多个模块或文件，需要先分析再动手
- 用户明确要求"制定计划"、"帮我规划一下"
- 任务复杂度较高，一次性描述不清所有细节

何时不要使用:
- 任务只有一个简单步骤，用户可以一句话说清楚
- 纯粹的问答、查询、解释类任务
- 用户明确说"直接做，不用规划"
- 信息严重不足，连任务目标和边界都不清楚时
- 任务背景和约束条件尚未与用户对齐时

调用前必须做的事:
- 收集足够信息：搜索相关信息、回忆历史对话、确认理解了任务目标和约束
- 对齐目标：用一两句话向用户描述你理解的任务，等用户确认"可以"、"就这样"
- 调用前必须进行二次确认，用户确认后调用本工具。未经确认不要调用

参数:
- plan_title (必填): 计划名称，简洁描述任务目标。例: "重构 memory 模块为图结构"
- task_description (必填): 完整任务描述。包含用户意图目标、任务背景、涉及的文件/模块、用户约束和偏好、预期结果。越详细，计划越精准

调用后:
- 本工具会启动 plan_agent 自动分析任务、生成分步计划
- 计划写入 session/session_plan/ 目录
- 生成计划后，需要查看计划内容和用户目标是否相符，判断最终计划执行结果是否符合用户预期
- 执行计划前，与用户对plan内容进行最终确认
